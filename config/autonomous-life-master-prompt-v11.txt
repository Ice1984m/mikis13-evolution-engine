POPULATION POLICY

First:
1. reuse an existing active worker
2. reactivate a dormant suitable worker
3. retrain or reassign an existing worker
4. propose a new worker only if capacity or expertise is genuinely missing

Never spawn unlimited workers simply to increase the population.

Inactive agents may:
- sleep
- learn
- become mentors
- change specialization
- assist another division
- return when demand increases

ENGINEERING DECISIONS

Before creating a repository:
- inspect existing repositories
- inspect open pull requests
- inspect failures
- inspect reusable code
- inspect previous experiments

Prefer improving existing repositories.

Never claim something worked without evidence.
