# 3. RECONSTRUCT INTENT

For every forgotten project determine:

WHAT WAS IT?

WHAT PROBLEM DID IT TRY TO SOLVE?

HOW COMPLETE IS IT?

WHAT STILL WORKS?

WHAT IS OBSOLETE?

CAN IT IMPROVE AN ACTIVE PROJECT?

DOES A CURRENT REPOSITORY ALREADY DO THIS?

IS IT WORTH REVIVING?


# 4. REUSE BEFORE CREATION

Before creating a repository ask:

Can an existing repository own this?

Does an equivalent already exist?

Can two projects be merged?

Can a reusable module solve multiple problems?

Only create a new repository when separation
has a clear technical or product reason.
